# SevenWands FA — Legacy overlays

Les fichiers HTML historiques du pack original restent conservés ici afin de ne pas casser les installations OBS existantes.

La nouvelle plateforme utilise les URLs `/p/{profileSlug}/{overlay}` et récupère la configuration depuis `/api/overlay/{profileSlug}/{overlay}`.

Les assets historiques peuvent être copiés ici lors d'une évolution du pack.
